# THREAT SCENARIOS → DETECTION STAGES (END-TO-END)

Detection stages follow the **Engine State Machine**:

```
Clean → Suspicious → Probable → Confirmed
```

---

## 1. RANSOMWARE (MODERN FILELESS + ENCRYPTOR)

### Scenario

User executes a trojanized binary → encrypts files → contacts C2 → exfiltrates keys.

### Stage Mapping

| Stage                 | Signal Source | What is Detected                    | Why It Matters               |
| --------------------- | ------------- | ----------------------------------- | ---------------------------- |
| Clean → Suspicious    | Linux Agent   | New process from `/tmp` or user dir | Untrusted execution context  |
| Suspicious            | Linux Agent   | Rapid file writes + entropy > 7.5   | Encryption behavior          |
| Suspicious            | DPI Probe     | New outbound TLS flow + rare JA3    | Potential C2                 |
| Suspicious → Probable | DPI Probe     | Beaconing periodicity               | Active C2 channel            |
| Probable              | Agent + DPI   | File encryption + network C2        | Multi-domain confirmation    |
| Probable → Confirmed  | AI Core       | Behavioral DNA match                | Ransomware family identified |

**Response**

* Kill process
* Isolate host
* Preserve evidence
* DPI validates containment

---

## 2. WORM (INTERNAL LATERAL PROPAGATION)

### Scenario

One infected host scans SMB/RDP and spreads internally.

### Stage Mapping

| Stage                 | Signal Source | Detection                    | Why                        |
| --------------------- | ------------- | ---------------------------- | -------------------------- |
| Clean → Suspicious    | DPI Probe     | SMB/RDP fan-out spike        | Abnormal east-west traffic |
| Suspicious            | DPI Probe     | SYN → RST bursts             | Failed auth scanning       |
| Suspicious            | Linux Agent   | New service/process spawn    | Payload execution          |
| Suspicious → Probable | DPI + Agent   | Scan + execution correlation | Propagation confirmed      |
| Probable → Confirmed  | Engine        | Multi-host graph expansion   | Worm classification        |

**Response**

* Network isolation
* Lateral movement containment
* Internal IOC sweep
