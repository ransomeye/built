## MITRE ATT&CK FRAMEWORK CONTEXT

MITRE ATT&CK is used here as the **taxonomy only**.
RansomEye does **behavioral detection**, not signature chasing.

---

# 1. RANSOMWARE (FILELESS + ENCRYPTOR)

### MITRE Mapping

| Tactic            | Technique ID | Technique Name                   | Detector |
| ----------------- | ------------ | -------------------------------- | -------- |
| Initial Access    | T1566        | Phishing                         | Agent    |
| Execution         | T1059        | Command & Scripting Interpreter  | Agent    |
| Execution         | T1204        | User Execution                   | Agent    |
| Defense Evasion   | T1027        | Obfuscated / Encrypted Files     | Agent    |
| Defense Evasion   | T1140        | Deobfuscate/Decode Files         | Agent    |
| Credential Access | T1555        | Credentials from Password Stores | Agent    |
| Discovery         | T1083        | File and Directory Discovery     | Agent    |
| Command & Control | T1071.001    | Web-based C2                     | DPI      |
| Command & Control | T1095        | Non-Application Layer Protocol   | DPI      |
| Exfiltration      | T1041        | Exfiltration Over C2 Channel     | DPI      |
| Impact            | T1486        | Data Encrypted for Impact        | Agent    |

**Why correlation matters**

* Agent confirms encryption
* DPI confirms live C2
* Combined = Confirmed ransomware
